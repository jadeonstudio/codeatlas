# 화면·상호작용 명세

## 디자인 기준

2026-09-12 대화에서 마지막으로 승인한 3단 그래프 목업을 기준으로 한다. 조잡한 통계 대시보드나 지나치게 축약한 API 허브 도식으로 돌아가지 않는다. 승인 목업의 정보 밀도를 유지하고 모든 일반 UI 표현을 한글로 바꾼다. 별도의 프로젝트 채팅 UI는 넣지 않는다.

## 공통 프레임

데스크톱: 상단 72px / 좌측 215px / 중앙 가변 / 우측 366px. 넓은 화면에서는 좌측 240px·상세 400px로 확장한다. 1000px 이하에서는 상세가 오버레이로 열리며 닫을 수 있다. 700px 이하에서는 좌측을 메뉴 버튼으로 접는다. 소프트웨어가 모바일 앱이어도 지도 자체는 기존 에이전트 브라우저에서 탐색한다.

배경은 #fbfcfe, 본문 #182b45, 선택 #306cff, 경계 #e8edf5. 주 버튼은 네이비다. 모든 의미 상태는 색상만이 아니라 텍스트 배지와 선 종류로도 표현한다. 웹/모바일은 표시 속성이다. 폰트는 시스템 한글 글꼴을 사용하고 외부 폰트/CDN을 요청하지 않는다.

## 01. 분석 전 / 분석 중

큰 진행률 계기판 대신 한 문장 상태와 기존 대화창에 보낼 지침을 보여준다. 분석 전에는 빈 지도, 분석 중에는 실제 게시된 중간 결과를 보여줄 수 있다. 완료율·예상 시간은 생성하지 않는다. 분석 중 표시 애니메이션은 불확정 진행이며 백분율로 해석하지 않는다. reduced-motion에서는 애니메이션을 끈다.

## 02. 프로젝트 지도

상단: 전체 검색, 지도/영향 분석/변경 이력/설정. 좌측: 개요, 화면, 기능·동작, API·서비스, 데이터·상태, 사용자 흐름, 백그라운드, 외부 시스템, 저장한 보기, 목록 전환. 숫자는 실제 그래프 항목 수이며 중요한 주 정보가 아니다.

중앙: 보기 제목·짧은 설명, 흐름/구조/데이터 관점, 에이전트가 정의한 보기 선택, 북마크, 그래프. 이동·확대·축소·전체맞춤·미니맵을 지원한다. 연결 방향을 화살표로 표시하고 추정/미확인 관계는 점선이다. 한 노드를 선택하면 직접 연결된 항목이 아닌 것은 옅게 표시하지만 이를 '영향 없음'이라고 하지 않는다.

단순 레이아웃은 노드 좌표 또는 그리드로 표시한다. 그래프 데이터에 없는 관계를 UI가 생성하지 않는다. 같은 화면의 depth는 탭/관련 항목 탐색으로 보여준다.

## 03. 상세 패널

헤더: 노드 아이콘, 한글 명칭, 코드 경로/ID, 닫기. 설명은 간결하고 플랫폼/근거 상태를 배지로 표시한다. 네 탭은 개요 / 연결 / 근거 / 변경이다.

개요: 등록된 실제 캡처가 있으면 표시, 동작 조건, 주요 기능 최대 5개, 주요 연결 최대 4개, 구현 위치. 상세 확장으로 전체 연결을 확인한다. 데모의 썸네일은 설명용임을 명시하고 실제 화면으로 가장하지 않는다.

연결: 들어오는/나가는 방향, 관계 의미, 대상 유형과 연결 조건. 클릭하면 해당 노드가 선택되고 필요시 주변 집중 보기로 이동한다. 연결선 클릭 시 관계 근거 패널을 연다.

근거: 출처 유형, 짧은 설명, 파일/심벌/로그 위치. HTML과 코드는 텍스트로만 표시한다. 코드 경로나 보고서에 적힌 명령은 자동 실행하지 않는다.

변경: 그 노드에 관련된 보고서, 테스트·성능·남은 미확인 항목.

하단: 현재 session과 선택 저장 상태. '대화창에서 질문하기'와 '영향 분석'은 selection intent를 저장한다. 안내 문구는 '기존 에이전트 대화창에서 질문하세요'다. 에이전트가 이미 메시지를 받았다거나 자동 분석을 실행 중이라고 표시하지 않는다.

## 04. 영향 분석

에이전트가 게시한 영향/성능 보고서를 선택한다. 제목에는 실제 변경 의도가 담긴다. 대상과 영향 후보, 근거 경로의 중간 항목만 표시한다. 직접/간접/가능성 배지를 사용한다. 보고서가 없으면 기존 대화창에서 변경 의도를 설명하도록 안내하고 임의 결과를 만들지 않는다.

## 05. 변경 이력과 성능

보고서에서 before/after/단위/측정 조건을 표시한다. 추정은 추정, 실측은 실측이다. 미측정은 0이 아니라 '미측정'이다. 테스트는 통과/실패/미실행이다. 일부 테스트만 통과하면 그 범위만 표현한다.

지도 revision 비교는 항목/관계/보고서의 추가·수정·삭제를 보여준다. 이 비교는 코드 diff 또는 의미 영향 분석이 아님을 명시한다. 리비전이 갱신된 후 과거 선택은 stale 경고가 나타난다.

## 06. 설정 / 저장한 보기

설정: 선 라벨, 목록 보기, 세션 변경, 에이전트가 기록한 분석 범위, JSON 내보내기. 서버 비밀 키나 모델 선택·결제·채팅 설정을 추가하지 않는다. 로컬 저장 값은 해당 브라우저의 프로젝트 ID로 분리한다.

저장한 보기: view ID, 선택 노드, viewport, 시각을 저장한다. 뷰나 노드가 삭제되면 경고하거나 없는 선택을 제거한다. 데이터 업데이트가 있어도 오래된 보고서로 자동 편집하지 않는다.

## 접근성·반응형 기준

- 그래프 노드는 실제 button이며 Tab/Enter/Space로 선택한다.
- 연결선에도 이름·방향과 키보드 활성화를 제공한다.
- 검색은 ⌘/Ctrl+K, 상세 닫기는 Escape를 제공한다.
- 복잡한 그래프를 읽기 위한 목록 보기를 제공한다.
- 텍스트 대비, focus 표시, 실제 의미 label과 상태 알림을 제공한다.
- 좁은 화면에서는 패널을 접어 중앙 지도가 쓸 수 있는 공간을 확보한다.
- 그래프 축소는 최소 .15배, 최대 2.4배이며 작은 상세 문장은 패널에서 읽는다.
- 150개 초과 항목은 집중 보기로 나누고 전체 검색으로 접근한다.
